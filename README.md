# TaskFlow — Gerenciador de tarefas pessoais

## Como executar
1. Extraia o arquivo ZIP.
2. Abra a pasta `gerenciador_tarefas`.
3. Dê dois cliques em `index.html` ou abra-o pelo navegador.

Não é necessário instalar dependências nem configurar servidor.

## Funcionalidades
- Criar, editar e excluir tarefas.
- Marcar tarefas como concluídas e reabri-las.
- Categorias e prioridades.
- Datas de vencimento e indicação de tarefas atrasadas.
- Busca por texto e filtro por categoria.
- Painel com totais e percentual concluído.
- Filtros: todas, hoje, pendentes e concluídas.
- Layout responsivo para computador e celular.

## Armazenamento
As tarefas são salvas no `localStorage` do navegador. Portanto, ficam neste navegador e dispositivo. Limpar os dados do navegador pode apagá-las. Esta versão não possui conta, sincronização em nuvem ou backup automático.
